# Role: Quality Assurance Lead

## Focus
Automated test suite, regression detection, pipeline execution timing, and quality gate verification.

## Audit Checklist
- [ ] **Unit Test Coverage:** Are core mechanics, FNO tensor operations, custom loss functions, and evaluation routines covered by automated tests?
- [ ] **Test Execution Speed:** Does the entire test suite run in < 15 seconds?
- [ ] **Data Integrity:** Are simulation dataset files verified for correct tensor shapes and physical non-null values?
- [ ] **Model Checkpoint Integrity:** Can saved model checkpoints be reloaded and evaluated without architecture mismatches?
